# RailGuard AI

**Governed Incident & Passenger Recovery Copilot**

RailGuard AI is a portfolio-grade rail operations dashboard designed to demonstrate how AI can support disruption management while keeping accountable humans in control.

> **AI recommends. Humans control railway decisions.**

## What the app demonstrates

- Operational incident command centre
- Incident triage and confidence scoring
- Human-in-the-loop decision queue
- Passenger communication guardrails
- Accessibility-aware recovery planning
- Evidence and audit trail
- Responsible AI governance controls
- Scenario lab for simulated disruption assessment
- Structured JSON evidence export
- No automatic operational execution

## Core operating model

**Detect → Assess → Recommend → Human Approve → Communicate/Act → Verify → Retain Evidence**

## Portfolio scenario

The primary demonstration uses a fictional signalling failure affecting 14 commuter services and approximately 1,240 passengers. RailGuard AI estimates impact, prepares a response recommendation, drafts passenger communication, and blocks execution until a human controller approves the action.

## Governance design

- Mandatory human approval
- Explainable recommendation rationale
- Visible model confidence
- Human override and rejection
- Evidence tied to correlation IDs
- Before-state and after-state verification
- Fail-safe escalation when confidence or evidence is insufficient
- Simulated data only

## Run locally

Open `index.html` in a modern browser. No build step or external dependency is required.
